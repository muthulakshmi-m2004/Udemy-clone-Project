# Udemy-clone-Project

A responsive front-end clone of the Udemy homepage built using pure HTML and CSS.

This project replicates the layout and design of Udemy’s main landing page to practice modern web development fundamentals.

---

## 🚀 Features

- ✅ Responsive Navigation Bar  
- ✅ Search Bar UI  
- ✅ Promotional Sale Banner with "Save Now" button  
- ✅ Recommended Courses Section  
- ✅ Popular Courses Grid Layout  
- ✅ Trending Topics Section  
- ✅ Structured Footer  
- ✅ Hover Effects & Clean UI Design  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Flexbox  
- Google Fonts  
- Font Awesome Icons  

---

## 📚 What I Learned

- Building structured layouts using Flexbox  
- Positioning elements using relative & absolute positioning  
- Creating reusable components (course cards)  
- Styling buttons and hover effects  
- Designing responsive web pages  

---

## 📌 Project Purpose

This project was created for educational purposes to improve my front-end development skills and understand real-world website layout structure.
